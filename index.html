Mock location, right from the map

gpsf is an open-source fake GPS / mock location app for Android. Tap any spot on an OpenStreetMap map and simulate your device location there — with a subtle 50 m jitter so the mock never looks “frozen”.

Android 8.0+ (API 26) Jetpack Compose + Material 3 OpenStreetMap (osmdroid) Foreground mock GPS service MIT licensed

Features

Everything you need for testing location-based features, in one small APK.

🗺️

Interactive OpenStreetMap

Powered by osmdroid — pan, zoom, and tap to choose any coordinate in the world.

📡

Foreground mock service

Simulates GPS + Network providers from a persistent foreground service, even while other apps run.

🎲

50 m random jitter

Adds a small random offset around your pin so the mock looks like real movement, not a static coordinate.

🎨

Material 3 UI

Modern Compose UI with dynamic color on Android 12+ and automatic dark / light mode.

⚙️

Developer Options shortcut

Jump straight to the “Select mock location app” setting to enable gpsf.

🔔

Active notification

Clear notification while mocking runs, so you always know when it’s active.

How to use

Setup takes about a minute: install, allow mock locations, pick a spot, press play.

  1. Install the APK from GitHub Releases.
  2. Enable Developer Options (tap Build number 7× under About phone).
  3. Open Settings → Developer Options → Select mock location app and choose gpsf.
  4. Open gpsf, tap the map to place a pin, then press the Play button.
  5. To stop, press Stop (the ✕ icon).
